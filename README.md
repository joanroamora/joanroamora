### 👨‍💻 Professional Summary

I am a **DevOps Engineer** based in **Houston, Texas** specializing in cloud infrastructure, automation, and containerized systems. I design and manage reliable cloud environments on AWS using Terraform and Ansible. I also work with Kubernetes and Docker to deploy microservices, and I set up full monitoring using Prometheus, Grafana, Loki, and Tempo (LGTM Stack). My focus is on building secure, scalable systems with automated CI/CD pipelines.

### 📂 Featured Projects

#### ⚡ [GridFlow-TX](https://github.com/joanroamora/gridflow-tx)
- **Description:** Analytics and monitoring platform for the Texas electrical grid (ERCOT) data and battery storage systems (BESS).
- **Highlights:** Includes real-time metrics, alerts, and complete system monitoring with Prometheus, Grafana, Loki, and Tempo.
- **Tech Stack:** AWS, Docker, Prometheus, Grafana, Loki, Tempo, Python.

#### 📄 [pdfRoar](https://github.com/joanroamora/pdfroar)
- **Description:** Microservices platform for processing PDF files (editing, merging, splitting, and text extraction).
- **Highlights:** Deployed on K3s Kubernetes and Docker clusters, configured with Ansible, and monitored with the LGTM stack.
- **Tech Stack:** K3s, Docker, Ansible, Nginx, Prometheus, Grafana, Loki, Tempo.

#### 🤖 [RealStateAgentic](https://github.com/joanroamora/RealStateAgentic-Feature1-FirstApproachInfraConfig)
- **Description:** AI-powered platform for real estate management.
- **Highlights:** Infrastructure provisioned using Terraform on AWS ECS Fargate inside secure VPCs and automated with Ansible.
- **Tech Stack:** AWS (ECS Fargate, VPC, ALB), Terraform, Ansible, Python.

#### 🎬 [youTubeProject](https://github.com/joanroamora/youTubeProject-Feature3Building)
- **Description:** Automated workflow pipeline for content processing and web scraping.
- **Highlights:** Features dynamic proxy rotation, task queues, and automated cloud setup with Terraform.
- **Tech Stack:** Terraform, AWS, Python, Celery, Redis, Docker.

#### 🛡️ [Open-Claw Test](https://github.com/joanroamora/open-clawtest)
- **Description:** Multi-tier application deployment on AWS.
- **Highlights:** Uses reusable Terraform modules for VPC networking, RDS databases, ElastiCache, ALB, and S3, configured with Ansible.
- **Tech Stack:** AWS (VPC, RDS, ElastiCache, ALB, S3), Terraform, Ansible.

#### ⚖️ [Operationalizing Fairness AI](https://github.com/joanroamora/operationalizing-fairness-ai)
- **Description:** Framework and unit testing suite to evaluate and reduce bias in machine learning models.
- **Highlights:** Automated tests to check model fairness and ensure ethical AI deployment.
- **Tech Stack:** Python, Scikit-learn, Automated Testing.

#### 🎥 [VideoForge RunPod](https://github.com/joanroamora/videoforge-runpod)
- **Description:** Backend infrastructure for AI video generation.
- **Highlights:** Optimized for Wan2.1 video workflows using cloud GPUs on RunPod.
- **Tech Stack:** RunPod Cloud GPUs, Python, PyTorch, Wan2.1, Docker.

#### 🏎️ [F1Genetics](https://github.com/joanroamora/f1genetics)
- **Description:** Autonomous racing simulation powered by AI.
- **Highlights:** Combines genetic algorithms and neural networks to train cars on F1 racetracks.
- **Tech Stack:** Python, Neural Networks, Genetic Algorithms.

#### 🔒 [LexShield](https://github.com/joanroamora/lexshield)

- **Highlights:** Containerized application with continuous integration pipelines powered by Jenkins.
- **Tech Stack:** Jenkins, Docker, Bash, Python.
